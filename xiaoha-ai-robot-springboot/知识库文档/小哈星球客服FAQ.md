## 关于星球（售前咨询）

### 星球是做什么的？

星球是博主「犬小哈」运营的 Java 项目实战社群，主打陪伴式项目实战教学。加入星球，你将获得：专属的项目实战专栏（如小哈书、AI 智能机器人项目、高并发秒杀系统、博客 Weblog 项目）、一对一提问答疑、简历优化指导、Java 学习路线、VIP 社群讨论、每月赠书以及学习打卡服务。

### 星球目前有几个项目？

目前星球已更新了 4 个项目，分别是：

- 《从零手撸: 前后端分离博客, Wiki 知识库》：
  - **介绍**：全栈开发，从 0 到 1 手敲一个前后端分离博客，包括前台以及后台管理，渐进式讲解每个功能模块的开发，直到部署到云服务器，实现公网域名可访问。
  - **试读链接**：https://www.quanxiaoha.com/column/10000.html。
  - **项目架构**：前后端分离; 后端单体 MVC 架构、Maven 多模块功能拆分; Element Plus、Flowbit 前端界面。
  - **项目技术栈**：Spring Boot 2.x、JDK 1.8、MySQL 5.7、MyBatis Plus、Spring Security、JWT、Minio、Lucene、Maven、Nginx、Docker、Jenkins、CI/CD、Vue 3.x、Vite 4、Element Plus、Tailwindcss、Pinia、Axios、Echarts、Flowbit ...

- 《从零手撸：小哈书（仿小红书）》：
  - **介绍**：从 0 到 1 搭建一个小红书，基于 Spring Cloud Alibaba 微服务架构。
  - **试读链接**：https://www.quanxiaoha.com/column/10247.html。
  - **项目架构**：后端微服务、分布式架构，Maven 多模块，业务组件设计; 前后端分离; Tailwindcss + Vue3 前端界面。
  - **项目技术栈**：Spring Boot 3.x、JDK 17、MySQL 8.0、Redis 7.x、Elasticsearch 7.x、Spring Cloud Alibaba 2022.x、Nacos、Gateway、Sentinel、RocketMQ、XXL-Job、MyBatis、SaToken、Minio、Cassandra、Zookeeper、Docker、Jmeter、Maven、Vue 3.x、Vite 4 ...

- 《从零手撸: Spring AI 应用项目（问答机器人、RAG 私有知识库、联网搜索）》：
  - **介绍**：全栈开发，基于 Spring AI 框架，从 0 到 1 手敲一个 AI 应用，初期规划是完成问答机器人、RAG 私有知识库、联网搜索（后续还会追加其他功能），包括前台以及后台管理，渐进式讲解每个功能模块的开发。
  - **试读链接**：https://www.quanxiaoha.com/column/10508.html。
  - **项目架构**：前后端分离; 后端单体 MVC 架构; Tailwindcss + Vue3 前端界面。
  - **项目技术栈**：Spring AI、Spring Boot 3.x、JDK 21、MySQL 8.x、Deepseek、Function Call、RAG 增强检索、MCP、Ollama、MyBatis Plus、PostgreSQL、Redis Stack、Cassandra、SaToken、JWT、Minio、Jsoup、Maven、Docker、Vue 3.x、Vite 4、Ant Design Vue、Tailwindcss、Pinia、Axios ...

- 《从零手撸：秒杀系统高并发优化实战》：
  - **介绍**：从 0 到 1，渐进式地搭建一个支撑高并发的秒杀系统。通过问题驱动、压测验证的方式，一步步攻克高并发场景下的核心难题：瞬时高并发流量、库存超卖、重复下单、黄牛刷单、服务雪崩、数据一致性等。
  - **试读链接**：https://www.quanxiaoha.com/column/10659.html
  - **项目架构**：Maven 多模块，后端单体 → 微服务、分布式架构演进。
  - **项目技术栈**：Spring Boot 3.x、JDK 21、MySQL 8.x、MyBatis、Redis 7.x、RabbitMQ / RocketMQ、Spring Cloud Alibaba 2022.x、Nacos、Gateway、Sentinel、Redisson、Docker、JMeter、FreeMark ...
